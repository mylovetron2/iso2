🔧 Bước 1: Setup Môi Trường Phát Triển

Thời gian: 1-2 tuần | Cấu hình đầy đủ Laravel, PostgreSQL, MongoDB và Docker

💻 1. Yêu Cầu Hệ Thống

Phần cứng tối thiểu:

Thành phần Yêu cầu Khuyến nghị
CPU 2 cores 4+ cores (Intel i5/i7, AMD Ryzen 5/7)
RAM 8 GB 16 GB+
Ổ cứng 50 GB trống 100 GB+ SSD
Hệ điều hành Windows 10/11, macOS 12+, Ubuntu 20.04+
💡 Lưu ý: Với Docker Desktop, bạn cần tối thiểu 8GB RAM. Nếu máy có 8GB, nên tắt các ứng dụng nặng khác khi phát triển.

🐘 2. Cài Đặt PHP 8.2 & Composer

Windows:

# 1. Download PHP 8.2 từ https://windows.php.net/download/ # 2. Giải nén vào C:\php82 # 3. Thêm C:\php82 vào PATH # 4. Copy php.ini-development thành php.ini copy C:\php82\php.ini-development C:\php82\php.ini # 5. Bật các extension cần thiết trong php.ini # Mở file C:\php82\php.ini và uncomment các dòng sau: extension=pdo_pgsql extension=pgsql extension=mongodb extension=redis extension=curl extension=mbstring extension=fileinfo # 6. Kiểm tra php -v

macOS (với Homebrew):

brew install php@8.2 brew link php@8.2 brew install mongodb/brew/mongodb-community pecl install mongodb redis # Kiểm tra php -v

Ubuntu/Debian:

sudo apt update sudo apt install php8.2 php8.2-cli php8.2-fpm php8.2-pgsql php8.2-mbstring \ php8.2-xml php8.2-curl php8.2-zip php8.2-redis # Cài MongoDB extension sudo pecl install mongodb echo "extension=mongodb.so" | sudo tee /etc/php/8.2/mods-available/mongodb.ini sudo phpenmod mongodb # Kiểm tra php -v

Cài đặt Composer:

# Download và cài đặt Composer php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');" php composer-setup.php php -r "unlink('composer-setup.php');" # Di chuyển vào PATH (Linux/macOS) sudo mv composer.phar /usr/local/bin/composer # Windows: Di chuyển vào C:\php82\composer.bat # Kiểm tra composer --version
✅ Kiểm tra thành công:
$ php -v PHP 8.2.15 (cli) $ composer --version Composer version 2.6.6

⚡ 3. Cài Đặt Node.js & npm

💡 Khuyến nghị: Sử dụng Node.js v18 LTS hoặc v20 LTS

Windows/macOS:

Download installer từ https://nodejs.org và cài đặt

Ubuntu/Debian:

# Sử dụng NVM (Node Version Manager) - Khuyến nghị curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash source ~/.bashrc nvm install 20 nvm use 20 # Kiểm tra node -v npm -v
✅ Kiểm tra thành công:
$ node -v v20.11.0 $ npm -v 10.2.4

🐳 4. Cài Đặt Docker Desktop

Windows/macOS:

  1. Download Docker Desktop từ https://www.docker.com/products/docker-desktop
  2. Cài đặt và khởi động Docker Desktop
  3. Chờ Docker daemon khởi động (có thể mất vài phút)

Ubuntu:

# Cài đặt Docker Engine curl -fsSL https://get.docker.com -o get-docker.sh sudo sh get-docker.sh # Thêm user vào docker group sudo usermod -aG docker $USER # Cài Docker Compose sudo apt install docker-compose-plugin # Khởi động Docker service sudo systemctl start docker sudo systemctl enable docker # Kiểm tra docker --version docker compose version
✅ Kiểm tra thành công:
$ docker --version Docker version 24.0.7 $ docker compose version Docker Compose version v2.23.3 # Test chạy container $ docker run hello-world Hello from Docker!

🗄️ 5. Setup PostgreSQL & MongoDB

💡 Khuyến nghị: Sử dụng Docker để chạy databases thay vì cài đặt trực tiếp. Dễ quản lý và xóa bỏ hơn.

Tạo file docker-compose.yml:

# docker-compose.yml version: '3.8' services: postgres: image: postgres:16-alpine container_name: pms_postgres environment: POSTGRES_DB: pms_core POSTGRES_USER: pms_user POSTGRES_PASSWORD: pms_pass123 ports: - "5432:5432" volumes: - postgres_data:/var/lib/postgresql/data networks: - pms_network mongodb: image: mongo:7 container_name: pms_mongodb environment: MONGO_INITDB_ROOT_USERNAME: admin MONGO_INITDB_ROOT_PASSWORD: admin123 MONGO_INITDB_DATABASE: pms_dynamic ports: - "27017:27017" volumes: - mongo_data:/data/db networks: - pms_network redis: image: redis:7-alpine container_name: pms_redis ports: - "6379:6379" volumes: - redis_data:/data networks: - pms_network volumes: postgres_data: mongo_data: redis_data: networks: pms_network: driver: bridge

Khởi động databases:

# Khởi động tất cả services docker compose up -d # Kiểm tra services đang chạy docker compose ps # Xem logs docker compose logs -f # Dừng services docker compose down # Dừng và xóa data docker compose down -v
✅ Test kết nối:
# Test PostgreSQL docker exec -it pms_postgres psql -U pms_user -d pms_core # Test MongoDB docker exec -it pms_mongodb mongosh -u admin -p admin123 # Test Redis docker exec -it pms_redis redis-cli ping
