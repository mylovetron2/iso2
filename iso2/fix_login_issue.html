🆘 PHP Error Log Location

Kiểm tra file log:

  • XAMPP: C:\xampp\apache\logs\error.log
  • WAMP: C:\wamp64\logs\php_error.log
  • Laravel Valet/Herd: ~/.config/valet/Log/
