**HOẶC** chạy trong phpMyAdmin:
1. Mở phpMyAdmin → Database `iso2`

3. Copy nội dung từng file và Execute

Đảm bảo user/role có đủ permissions:

File permissions SQL đã tự động gán cho role Admin (id=1).

### Bước 3: Test Chức Năng

1. **Login vào hệ thống**
2. **Vào trang "Vật tư thanh lý"**
   - Kiểm tra thấy 3 nút mới:
     - 🛒 "Tạo phiếu đặt hàng" (cam)
     - 👜 "Giỏ hàng" (tím) + badge
     - 📄 "Quản lý phiếu ĐH" (indigo)
   - Mỗi dòng vật tư có icon 🛒+ (thêm vào giỏ)

3. **Test Giỏ Hàng**
   - Click icon 🛒+ ở vài vật tư
   - Kiểm tra badge tăng lên
   - Vào "Giỏ hàng" → xem danh sách
   - Thay đổi số lượng, ghi chú
   - Click "Tạo Phiếu Đặt Hàng"

4. **Test Phiếu Đặt Hàng**
   - Điền form tạo phiếu
   - Lưu phiếu → xem chi tiết
   - Duyệt phiếu (nếu có quyền)
   - Nhận hàng → Nhập kho
   - Kiểm tra tồn kho đã tăng chưa

## 🔧 TROUBLESHOOTING

### "Không thấy nút Giỏ hàng"
→ Chạy lại file `add_giohang_phieudathang_permissions.sql`

### "Badge không hiển thị số lượng"
→ Mở F12 Console, kiểm tra lỗi JavaScript
→ Kiểm tra URL: `giohang.php?action=getCount` có chạy không

### "Lỗi khi thêm vào giỏ"
→ Kiểm tra bảng `cart_vattu_thanh_ly` đã tạo chưa
→ Check error log PHP

### "Nhập kho không cập nhật tồn"
→ Kiểm tra cột `soluong_conlai` có trong bảng `vattu_thanh_ly_iso`
