🔧 Khắc phục lỗi Menu

⚠️ Nguyên nhân lỗi:
Menu bị lỗi vì permissions congviec_suachua.* chưa tồn tại trong database. Function hasPermission() không thể check permission không tồn tại.

🚀 BƯỚC 1: Chạy Migration

Click nút bên dưới để tạo permissions trong database:

▶️ Chạy Migration Ngay

Script sẽ tạo 4 permissions: view, create, edit, delete

✅ BƯỚC 2: Sau khi Migration thành công

  1. Đăng xuất khỏi hệ thống
  2. Đăng nhập lại
  3. Menu sẽ hiển thị bình thường
✅ Sau khi hoàn tất:
- Menu item "Công việc sửa chữa" sẽ hiện (nếu có quyền)
- Không còn lỗi khi load trang
- Có thể quản lý permissions trong Admin → Permissions Manager

🔍 Alternative: Tạm thời vô hiệu hóa menu item

Nếu không muốn chạy migration ngay, có thể tạm comment menu item:

<!-- Tạm thời comment -->
<?php if (false): ?>  // Thay isLoggedIn() && hasPermission('congviec_suachua.view')
<li>
    <a href="/iso2/congviec_suachua.php"...>
        <i class="fas fa-tasks mr-2"></i> Công việc sửa chữa
    </a>
</li>
<?php endif; ?>

Sau đó chạy migration và đổi lại false thành isLoggedIn() && hasPermission('congviec_suachua.view')

📞 Hỗ trợ

Nếu vẫn gặp lỗi sau khi chạy migration:

  1. Kiểm tra PHP error log
  2. Verify permissions trong database: SELECT * FROM permissions WHERE name LIKE 'congviec_suachua.%'
  3. Clear browser cache (Ctrl+Shift+Del)
  4. Đăng xuất và đăng nhập lại
