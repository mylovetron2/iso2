1. Technology Stack Chính

⚙️ Backend Framework

NestJS / Spring Boot

Ưu điểm NestJS:

  • Microservices native
  • TypeScript (type-safe)
  • Modular architecture
  • WebSocket support

🎨 Frontend Framework

React + Next.js

Stack đầy đủ:

  • React 18+ (UI components)
  • Next.js 14 (SSR, routing)
  • TypeScript
  • Tailwind CSS + Ant Design

💾 Database Hybrid

SQL + NoSQL

PostgreSQL 16: Core data

MongoDB 7: Dynamic schemas

Redis 7: Caching & Queue

🚀 Orchestration

Kubernetes + Docker

Container: Docker

Orchestration: K8s

CI/CD: GitLab CI/Jenkins

📋 III. CÁC MODULE CHÍNH

Module 1: Quản Lý Kế Hoạch Sản Xuất (G1)

🎯 Chức năng chính:

  • Lập kế hoạch sản xuất theo năm/quý/tháng
  • Import CSV/Excel từ Oracle ERP
  • Phân công nhiệm vụ với Gantt Chart
  • Workflow phê duyệt (Kế hoạch → Trưởng phòng → Giám đốc)
  • Cảnh báo vật tư, thiết bị, nhân lực thiếu
// Database Schema - PostgreSQL CREATE TABLE production_plans ( id UUID PRIMARY KEY, code VARCHAR(50) UNIQUE NOT NULL, name VARCHAR(255) NOT NULL, enterprise_id UUID REFERENCES enterprises(id), start_date TIMESTAMP, end_date TIMESTAMP, status VARCHAR(20), -- draft, approved, in_progress, completed kpi_targets JSONB, -- Flexible KPI storage created_by UUID, approved_by UUID, created_at TIMESTAMP DEFAULT NOW() ); CREATE TABLE plan_tasks ( id UUID PRIMARY KEY, plan_id UUID REFERENCES production_plans(id), parent_task_id UUID, -- For subtasks name VARCHAR(255), assigned_to UUID[], assigned_enterprise_id UUID, -- Liên đơn vị priority INT, dependencies UUID[], -- Task dependencies status VARCHAR(20), metadata JSONB -- Dynamic fields per enterprise );

Module 2: Quản Lý Nhiệm Vụ & Theo Dõi (G2-G4)

🎯 Chức năng chính:

  • Kanban Board (drag & drop)
  • Real-time updates qua WebSocket
  • Notification (Email + In-app)
  • Theo dõi tiến độ theo thời gian thực
  • SLA tracking & Escalation

Module 3: Giao Việc Liên Đơn Vị

🎯 Chức năng chính:

  • Giao nhiệm vụ từ xí nghiệp này sang xí nghiệp khác
  • Theo dõi tiến độ chéo đơn vị
  • Message Queue (RabbitMQ) cho async communication
  • SLA monitoring & Alert

Module 4: Báo Cáo & Dashboard (G5)

🎯 Chức năng chính:

  • Dashboard real-time (KPI, SLA, Progress)
  • Report generation (PDF, Excel)
  • Cost analysis (Dự toán vs Thực tế)
  • AI prediction (resource forecasting)
  • Export API cho My VSP
