🎯 Mục Tiêu Bước Này

  • ✅ Cài đặt PHP 8.2+ & Composer
  • ✅ Cài đặt Node.js 20+ & npm
  • ✅ Cài đặt Docker Desktop (cho PostgreSQL, MongoDB, Redis)
  • ✅ Cài đặt VS Code & Extensions
  • ✅ Setup Laravel project mới

1. Cài Đặt PHP 8.2 & Composer

📦 PHP 8.2 (Windows)

Cách 1: Dùng XAMPP (Dễ nhất cho người mới)

  1. Download: https://www.apachefriends.org/
  2. Cài đặt XAMPP (chọn PHP 8.2)
  3. Thêm vào System PATH: C:\xampp\php

Cách 2: Dùng Laragon (Khuyến nghị cho Laravel)

  1. Download: https://laragon.org/download/
  2. Cài đặt Laragon Full (có sẵn PHP, MySQL, Node.js)
  3. Laragon tự động cấu hình PATH
# Kiểm tra PHP đã cài đặt php -v # Output mong muốn: # PHP 8.2.x (cli) (built: ...)

📦 Composer (PHP Package Manager)

  1. Download: https://getcomposer.org/download/
  2. Chạy Composer-Setup.exe
  3. Chọn đường dẫn PHP đã cài (ví dụ: C:\xampp\php\php.exe)
# Kiểm tra Composer composer --version # Output: Composer version 2.x.x

2. Cài Đặt Node.js & npm

🟢 Node.js 20 LTS

  1. Download: https://nodejs.org/
  2. Chọn phiên bản LTS (Long Term Support)
  3. Cài đặt với tùy chọn mặc định
# Kiểm tra Node.js và npm node -v # Output: v20.x.x npm -v # Output: 10.x.x

⚠️ Nếu gặp lỗi "node not found"

Khởi động lại Command Prompt hoặc PowerShell sau khi cài đặt

3. Cài Đặt Docker Desktop

🐳 Docker Desktop (PostgreSQL, MongoDB, Redis)

  1. Download: https://www.docker.com/products/docker-desktop/
  2. Cài đặt Docker Desktop for Windows
  3. Khởi động Docker Desktop
  4. Đợi Docker engine khởi động (icon ở system tray)
# Kiểm tra Docker docker --version # Output: Docker version 24.x.x docker-compose --version # Output: Docker Compose version v2.x.x

📝 Tại sao dùng Docker?

  • ✅ Không cần cài PostgreSQL, MongoDB trực tiếp lên Windows
  • ✅ Dễ dàng start/stop services
  • ✅ Cấu hình giống production
  • ✅ Dễ deploy sau này

4. Cài Đặt VS Code & Extensions

📝 Visual Studio Code

  1. Download: https://code.visualstudio.com/
  2. Cài đặt với các tùy chọn:
    • ☑️ Add "Open with Code" to Windows Explorer context menu
    • ☑️ Add to PATH

5. Tạo Laravel Project Mới

🚀 Khởi Tạo Project

# Tạo project Laravel mới composer create-project laravel/laravel pms-vietsovpetro # Di chuyển vào thư mục project cd pms-vietsovpetro # Mở VS Code code .

📦 Cài Đặt Dependencies

# Cài Laravel Sanctum (Authentication) composer require laravel/sanctum # Cài MongoDB driver composer require mongodb/laravel-mongodb # Cài Laravel Reverb (WebSocket) composer require laravel/reverb # Publish config files php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider" php artisan vendor:publish --provider="MongoDB\Laravel\MongoDBServiceProvider" php artisan reverb:install

🐳 Docker Compose Setup

Tạo file docker-compose.yml trong thư mục project:

# docker-compose.yml version: '3.8' services: postgres: image: postgres:16-alpine container_name: pms_postgres restart: unless-stopped environment: POSTGRES_DB: pms_db POSTGRES_USER: pms_user POSTGRES_PASSWORD: pms_password ports: - "5432:5432" volumes: - postgres_data:/var/lib/postgresql/data mongodb: image: mongo:7 container_name: pms_mongodb restart: unless-stopped environment: MONGO_INITDB_ROOT_USERNAME: admin MONGO_INITDB_ROOT_PASSWORD: admin_password MONGO_INITDB_DATABASE: pms_dynamic ports: - "27017:27017" volumes: - mongodb_data:/data/db redis: image: redis:7-alpine container_name: pms_redis restart: unless-stopped ports: - "6379:6379" volumes: - redis_data:/data volumes: postgres_data: mongodb_data: redis_data:
# Khởi động Docker containers docker-compose up -d # Kiểm tra containers đang chạy docker-compose ps # Output: # NAME IMAGE STATUS # pms_postgres postgres:16-alpine Up # pms_mongodb mongo:7 Up # pms_redis redis:7-alpine Up

⚙️ Cấu Hình .env

# .env - Database connections DB_CONNECTION=pgsql DB_HOST=127.0.0.1 DB_PORT=5432 DB_DATABASE=pms_db DB_USERNAME=pms_user DB_PASSWORD=pms_password # MongoDB connection MONGODB_CONNECTION=mongodb MONGODB_HOST=127.0.0.1 MONGODB_PORT=27017 MONGODB_DATABASE=pms_dynamic MONGODB_USERNAME=admin MONGODB_PASSWORD=admin_password # Redis REDIS_HOST=127.0.0.1 REDIS_PASSWORD=null REDIS_PORT=6379 # Laravel Reverb BROADCAST_CONNECTION=reverb REVERB_APP_ID=pms-app REVERB_APP_KEY=pms-key-local REVERB_APP_SECRET=pms-secret-local REVERB_HOST=localhost REVERB_PORT=8080 REVERB_SCHEME=http

🧪 Test Connection

# Test PostgreSQL connection php artisan tinker >>> DB::connection('pgsql')->getPdo(); # Nếu không lỗi => kết nối thành công! >>> DB::connection('mongodb')->getMongoDB(); # Nếu không lỗi => MongoDB OK! >>> exit

🏃 Chạy Laravel Development Server

# Terminal 1: Laravel server php artisan serve # Terminal 2: Laravel Reverb (WebSocket) php artisan reverb:start # Output: # Laravel development server started: http://127.0.0.1:8000 # Reverb server started on ws://localhost:8080

Mở trình duyệt: http://localhost:8000

Nếu thấy trang Laravel chào mừng → ✅ Setup thành công!

✅ Checklist Hoàn Thành

  • ☑️ PHP 8.2+ installed & verified
  • ☑️ Composer installed
  • ☑️ Node.js 20+ & npm installed
  • ☑️ Docker Desktop installed & running
  • ☑️ VS Code + Extensions installed
  • ☑️ Laravel project created
  • ☑️ Docker containers running (PostgreSQL, MongoDB, Redis)
  • ☑️ .env configured
  • ☑️ Database connections tested
  • ☑️ Laravel server running on http://localhost:8000
  • ☑️ Reverb WebSocket running on ws://localhost:8080

⚠️ Lưu Ý

  • Mỗi lần bật máy, phải chạy docker-compose up -d để khởi động databases
  • Commit code lên GitHub/GitLab ngay sau khi setup xong
  • Backup file .env (nhưng không commit lên Git!)
