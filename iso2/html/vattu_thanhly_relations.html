Vật tư thanh lý — Quan hệ bảng & luồng dữ liệu

Mô tả quan hệ giữa các bảng của module vattuthanhly.php, giohang.php, phieudathang.php, phanloaivattu.php, phieu kiểm soát vật tư và thongke_vattu_thanh_ly.php.

1. Tổng quan

Bảng trung tâm là vattu_thanh_ly_iso (danh mục + tồn kho). Mọi chức năng đều xoay quanh bảng này:

  • Xuất / thanh lý: INSERT vattu_thanh_ly_sudung_iso + UPDATE vattu_thanh_ly_iso SET soluong_conlai = soluong_conlai − soluong (trong transaction).
  • Xoá chi tiết sử dụng: DELETE dòng sử dụng + cộng lại soluong_conlai.
  • Nhập kho từ phiếu đặt hàng: UPDATE so_luong_nhan, soluong_conlai += so_luong_nhan, INSERT lich_su_nhap_kho, cập nhật trang_thai phiếu.
  • Phiếu kiểm soát: soluong_tieuhao > 0 ⇒ INSERT sử dụng (trangthai='dangdung') + trừ tồn. Huỷ phiếu và xoá dòng sử dụng sẽ hoàn lại số lượng.

7. Thống kê vật tư thanh lý

Trang thongke_vattu_thanh_ly.php (ThongKeVatTuThanhLyController::getThanhLyByDateRange) chỉ đọc dữ liệu, truy vấn theo khoảng ngày:

FROM vattu_thanh_ly_sudung_iso s
INNER JOIN vattu_thanh_ly_iso v           ON s.vattu_stt = v.stt
LEFT  JOIN phanloai_vattu_thanh_ly_iso pl ON v.phanloai_id = pl.id
WHERE DATE(COALESCE(s.ngayhoanthanh, s.ngaysd_nhan, s.updated_at)) BETWEEN :tungay AND :denngay
  [AND v.phanloai_id = :phanloai_id]
  [AND s.bophan = :bophan   -- DVLTH ⇒ s.bophan IN ('TH','CNC')]
  [AND (v.mavattu / ten_* / s.ghichu / s.bophan / s.nguoisudung LIKE :search)]
ORDER BY ngay_thuchien, v.mavattu

Trang danh sách vật tư (VatTuThanhLy::getAllWithStats) cũng tính thống kê bằng JOIN phân loại + sử dụng: số lần dùng (COUNT), số lượng đang dùng (SUM với trangthai='dangdung'), tổng giá trị (soluong_conlai × dongia).
