Hồ sơ SCBĐ & Định mức KPI — Tài liệu chức năng

Mô tả quan hệ bảng CSDL và cách hệ thống hiển thị cột Định mức cho hồ sơ sửa chữa bảo dưỡng trong hososcbd.php.

1. Tổng quan

  • Cột Định mức của mỗi hồ sơ đọc trực tiếp từ hososcbd_dinhmuc_iso.dinh_muc_gio_thu_cong — đây là cột duy nhất lưu số giờ định mức cho hồ sơ.
  • kpi_baoduong_thietbi_iso + thietbi_kpi_baoduong_iso lưu định mức chuẩn của thiết bị, chỉ được UI tra cứu để gợi ý khi người dùng chọn định mức. Kết quả gợi ý được resolve thành số và ghi thẳng vào dinh_muc_gio_thu_cong.
  • Cột hososcbd_dinhmuc_iso.kpi_baoduong_stt chỉ còn ý nghĩa audit ("đã chọn từ bộ KPI nào"), không còn FK tới kpi_baoduong_thietbi_iso.
  • Giờ thực tế lấy từ ngthuchien_iso (nối theo hoso) để tính kết luận đạt / không đạt.
  • Hai view view_hososcbd_kpi_dinhmuc và view_hososcbd_kpi_ketluan tổng hợp dữ liệu để trang danh sách chỉ cần SELECT.
Phạm vi: hososcbd.php Migrations: 20260714, 20260810, 20260811, 20260925 Cập nhật: 2026-09-25

2. Sơ đồ quan hệ bảng (ERD)

erDiagram hososcbd_iso ||--o| hososcbd_dinhmuc_iso : "1 hồ sơ → 0..1 định mức riêng" hososcbd_iso ||--o{ ngthuchien_iso : "1 hồ sơ → n người thực hiện (mahoso = hoso)" thietbi_iso ||--o| thietbi_kpi_baoduong_iso : "1 thiết bị → 0..1 gán KPI" thietbi_kpi_baoduong_iso }o--|| kpi_baoduong_thietbi_iso : "gán bộ KPI chuẩn" hososcbd_iso }o..o| thietbi_iso : "UI gợi ý: mavt + somay" hososcbd_iso ||--o{ view_hososcbd_kpi_dinhmuc : "view tổng hợp định mức" hososcbd_iso ||--o{ view_hososcbd_kpi_ketluan : "view kết luận KPI" hososcbd_iso { INT stt PK VARCHAR hoso VARCHAR phieu VARCHAR mavt VARCHAR somay DATE ngayyc DATE ngayth DATE ngaykt } hososcbd_dinhmuc_iso { INT id PK INT hososcbd_stt FK DECIMAL dinh_muc_gio_thu_cong ENUM loai_congviec INT kpi_baoduong_stt } kpi_baoduong_thietbi_iso { INT id PK VARCHAR ten_thiet_bi DECIMAL kiem_tra_so_gio DECIMAL bd_cap_1_so_gio DECIMAL bd_cap_2_so_gio DECIMAL bd_cap_3_so_gio DECIMAL hieu_chuan_so_gio } thietbi_iso { INT stt PK VARCHAR mavt VARCHAR somay VARCHAR tenvt } thietbi_kpi_baoduong_iso { INT id PK INT thietbi_stt FK INT kpi_baoduong_stt FK } ngthuchien_iso { INT stt PK VARCHAR mahoso FK VARCHAR hoten DECIMAL giolv } view_hososcbd_kpi_dinhmuc { INT hososcbd_stt DECIMAL dinh_muc_so_gio DECIMAL gio_thuc_te } view_hososcbd_kpi_ketluan { INT hososcbd_stt VARCHAR ket_luan_kpi }

Đường liền = quan hệ trực tiếp qua FK. Đường chấm hososcbd_iso ..o| thietbi_iso là quan hệ gợi ý phía UI nối theo cặp mavt + somay (không có FK). Cụm kpi_baoduong_thietbi_iso + thietbi_kpi_baoduong_iso chỉ lưu định mức chuẩn của thiết bị; UI đọc để đề xuất số giờ, giá trị được ghi thẳng vào hososcbd_dinhmuc_iso.dinh_muc_gio_thu_cong.

3.6. VIEW Các view tổng hợp

  • view_hososcbd_kpi_dinhmuc: trả về dinh_muc_so_gio = hososcbd_dinhmuc_iso.dinh_muc_gio_thu_cong và gio_thuc_te = MAX(ngthuchien_iso.giolv).
  • view_hososcbd_kpi_ketluan: dựa vào view trên để trả về ket_luan_kpi với 3 trạng thái: chua_du_du_lieu, dat, khong_dat.

5. Luồng hiển thị cột "Định mức"

flowchart LR U[UI: form định mức hồ sơ] --> C{Người dùng nhập tay giờ?} C -- Có --> H[dinh_muc_gio_thu_cong = số nhập tay] C -- Không --> S[Chọn thiết bị KPI + loại công việc] S --> R[UI resolve giờ từ kpi_baoduong_thietbi_iso theo loai_congviec] R --> H H --> W[(hososcbd_dinhmuc_iso)
dinh_muc_gio_thu_cong = giờ
kpi_baoduong_stt = audit] W --> V[view_hososcbd_kpi_dinhmuc
dinh_muc_so_gio = dinh_muc_gio_thu_cong] V --> K[view_hososcbd_kpi_ketluan] K --> L{gio_thuc_te ≤ dinh_muc?} L -- Thiếu dữ liệu --> O[chua_du_du_lieu] L -- Đạt --> M[dat] L -- Không đạt --> N[khong_dat]

6. Cách tính "Định mức giờ"

  1. Cột hososcbd_dinhmuc_iso.dinh_muc_gio_thu_cong là nguồn duy nhất cho cột Định mức của hồ sơ.
  2. Khi người dùng nhập tay số giờ trên form → ghi trực tiếp vào cột.
  3. Khi người dùng chọn thiết bị KPI + loại công việc trên UI → UI tra kpi_baoduong_thietbi_iso để resolve số giờ, rồi ghi vào cột. kpi_baoduong_stt và loai_congviec được lưu kèm để audit.
  4. Nếu hồ sơ chưa có dòng trong hososcbd_dinhmuc_iso → hiển thị "—".
