1. Laravel Reverb - Setup WebSocket Server

📦 Cài Đặt Laravel Reverb

# 1. Install Laravel Reverb composer require laravel/reverb # 2. Publish config php artisan reverb:install # 3. Migrate database (for presence channels) php artisan migrate

📝 Laravel Reverb là gì?

Laravel Reverb là WebSocket server chính thức của Laravel (ra mắt Laravel 11), thay thế cho Pusher/Socket.io.

Ưu điểm:

  • ✅ Miễn phí, không giới hạn connections
  • ✅ Tích hợp sẵn với Laravel Broadcasting
  • ✅ Hỗ trợ Presence Channels (theo dõi users online)
  • ✅ Performance tốt (built trên ReactPHP)

⚙️ Cấu Hình .env

# .env BROADCAST_CONNECTION=reverb REVERB_APP_ID=your-app-id REVERB_APP_KEY=your-app-key REVERB_APP_SECRET=your-app-secret REVERB_HOST=localhost REVERB_PORT=8080 REVERB_SCHEME=http # For production (SSL) # REVERB_SCHEME=https

🚀 Chạy Reverb Server

# Terminal riêng cho Reverb (để chạy background) php artisan reverb:start # Hoặc với debug mode php artisan reverb:start --debug # Output: # [2026-01-19 10:00:00] Reverb server started on ws://localhost:8080

2. Broadcasting Events - Backend

📡 Tạo Event Class

// app/Events/TaskUpdated.php namespace App\Events; use App\Models\Task; use Illuminate\Broadcasting\Channel; use Illuminate\Broadcasting\InteractsWithSockets; use Illuminate\Contracts\Broadcasting\ShouldBroadcast; use Illuminate\Foundation\Events\Dispatchable; use Illuminate\Queue\SerializesModels; class TaskUpdated implements ShouldBroadcast { use Dispatchable, InteractsWithSockets, SerializesModels; public Task $task; public string $action; // 'updated', 'status_changed', 'assigned' public function __construct(Task $task, string $action = 'updated') { $this->task = $task; $this->action = $action; } // Broadcast on public channel (all users can listen) public function broadcastOn(): Channel { return new Channel('tasks'); } // Custom event name public function broadcastAs(): string { return 'task.updated'; } // Data to broadcast public function broadcastWith(): array { return [ 'id' => $this->task->id, 'name' => $this->task->name, 'status' => $this->task->status, 'action' => $this->action, 'updated_at' => $this->task->updated_at->toISOString(), 'updated_by' => $this->task->updatedBy->name ?? null, ]; } }

🔥 Dispatch Event trong Controller

// app/Http/Controllers/TaskController.php use App\Events\TaskUpdated; public function update(Request $request, $id) { $task = Task::findOrFail($id); $oldStatus = $task->status; $task->update($request->validated()); // Broadcast event to all connected clients event(new TaskUpdated( $task, $oldStatus !== $task->status ? 'status_changed' : 'updated' )); return response()->json(['task' => $task]); }

💬 Private Channel (Chỉ user được assign mới nhận)

// app/Events/TaskAssigned.php public function broadcastOn(): Channel { // Private channel cho từng user return new PrivateChannel('user.' . $this->task->assigned_to); } // routes/channels.php - Authorize private channels Broadcast::channel('user.{userId}', function ($user, $userId) { return (int) $user->id === (int) $userId; });

3. React WebSocket Client

📦 Install Laravel Echo & Pusher JS

# Frontend (React project) npm install laravel-echo pusher-js

⚙️ Setup Echo Instance

// src/lib/echo.js import Echo from 'laravel-echo'; import Pusher from 'pusher-js'; window.Pusher = Pusher; const echo = new Echo({ broadcaster: 'reverb', key: import.meta.env.VITE_REVERB_APP_KEY, wsHost: import.meta.env.VITE_REVERB_HOST, wsPort: import.meta.env.VITE_REVERB_PORT ?? 8080, wssPort: import.meta.env.VITE_REVERB_PORT ?? 8080, forceTLS: (import.meta.env.VITE_REVERB_SCHEME ?? 'https') === 'https', enabledTransports: ['ws', 'wss'], // Auth for private channels authEndpoint: 'http://localhost:8000/broadcasting/auth', auth: { headers: { Authorization: `Bearer ${localStorage.getItem('token')}`, }, }, }); export default echo;
# .env.local (React) VITE_REVERB_APP_KEY=your-app-key VITE_REVERB_HOST=localhost VITE_REVERB_PORT=8080 VITE_REVERB_SCHEME=http

🎧 Listen to Events trong React Component

// src/pages/TaskBoard.jsx import { useEffect } from 'react'; import { useQueryClient } from '@tanstack/react-query'; import { message } from 'antd'; import echo from '../lib/echo'; function TaskBoard() { const queryClient = useQueryClient(); useEffect(() => { // Listen to public channel 'tasks' echo.channel('tasks') .listen('.task.updated', (event) => { console.log('Task updated:', event); // Show notification if (event.action === 'status_changed') { message.info( `Task "${event.name}" status changed to ${event.status}` ); } // Invalidate React Query cache to refetch queryClient.invalidateQueries(['tasks']); }); // Cleanup on unmount return () => { echo.leaveChannel('tasks'); }; }, [queryClient]); return ( <div> {/* Your Kanban board */} </div> ); }

🔔 Real-time Notifications

// src/components/NotificationBell.jsx import { useState, useEffect } from 'react'; import { Badge, Dropdown, List } from 'antd'; import { BellOutlined } from '@ant-design/icons'; import echo from '../lib/echo'; function NotificationBell({ userId }) { const [notifications, setNotifications] = useState([]); const [unreadCount, setUnreadCount] = useState(0); useEffect(() => { // Listen to private channel for this user echo.private(`user.${userId}`) .listen('.task.assigned', (event) => { const newNotif = { id: Date.now(), message: `Bạn được giao nhiệm vụ: ${event.task_name}`, time: new Date(), unread: true }; setNotifications(prev => [newNotif, ...prev]); setUnreadCount(prev => prev + 1); // Browser notification if (Notification.permission === 'granted') { new Notification('Nhiệm vụ mới', { body: newNotif.message, icon: '/logo.png' }); } }); return () => echo.leaveChannel(`user.${userId}`); }, [userId]); const menu = ( <List dataSource={notifications.slice(0, 5)} renderItem={item => ( <List.Item>{item.message}</List.Item> )} /> ); return ( <Dropdown overlay={menu}> <Badge count={unreadCount}> <BellOutlined style={{ fontSize: 20 }} /> </Badge> </Dropdown> ); }

4. Presence Channels (Users Online)

👥 Theo Dõi Users Online

// Backend - routes/channels.php Broadcast::channel('online-users', function ($user) { return [ 'id' => $user->id, 'name' => $user->name, 'avatar' => $user->avatar_url, ]; });
// Frontend - Track online users import { useState, useEffect } from 'react'; import { Avatar, Tooltip } from 'antd'; import echo from '../lib/echo'; function OnlineUsers() { const [users, setUsers] = useState([]); useEffect(() => { const channel = echo.join('online-users') .here((users) => { // Initial list of online users setUsers(users); }) .joining((user) => { // User joined setUsers(prev => [...prev, user]); }) .leaving((user) => { // User left setUsers(prev => prev.filter(u => u.id !== user.id)); }); return () => echo.leave('online-users'); }, []); return ( <div style={{ display: 'flex', gap: 8 }}> {users.map(user => ( <Tooltip key={user.id} title={user.name}> <Avatar src={user.avatar} /> </Tooltip> ))} <span>{users.length} online</span> </div> ); }
